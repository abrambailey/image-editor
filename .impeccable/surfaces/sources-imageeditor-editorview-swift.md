# Editor surface

- **Target:** `Sources/ImageEditor/EditorView.swift`; related `Sources/ImageEditor/CanvasView.swift`, `Sources/ImageEditor/ImageEditorApp.swift`, `Sources/ImageEditor/EditorWorkspace.swift`, and `Sources/ImageEditor/EditorWorkspaceView.swift`.

- **Unexported work:** A small semantic dot beside each tab title indicates that its current state has not been exported to a file. Close Tab, the native window close button, and Quit protect changed work with an AppKit alert offering Export…, Cancel, and Don’t Export. Export is the default when a canvas can be exported; Cancel remains available when the last layer was deleted. The dialog explains that PNG/JPG output is flattened and does not save editable layers or Undo history. Canceled or failed saves and clipboard copies do not acknowledge an export. Undo back to the exported state clears the dot. Busy operations and pending crops must finish or be canceled before quitting. Closed tabs enter the bounded recovery list only after export or explicit discard.

## Clipboard copy

- **Entry:** Copy Image beside Export in the native toolbar, beneath the inspector's Export button, and in the Edit menu with Shift-Command-C. Standard Command-C copies the image when the canvas is focused and selected text when a text field is focused. Uses the existing native secondary button style and `doc.on.doc` symbol; fixed inspector access remains visible at the minimum window size.
- **Behavior:** Copies the visible layer composition as a flattened, full-quality PNG using the current export bounds setting, preserving transparency and the selected canvas background regardless of the file export format. Pending numeric edits commit before rendering. Copy is disabled without an image, during cropping, and while busy; successful writes confirm “Image copied. Paste it with ⌘V.” in the status bar, and failed writes use the existing error alert.

## Preview zoom shortcuts

- **Entry:** Command-plus / Command-minus, or Command-equals for zooming in without Shift. Status-bar zoom controls share the same actions and show shortcut hints. Command-zero retains Fit Preview to Window.
- **Behavior:** Adjust preview zoom in 25-point percentage steps, clamped to 25%–400% of fit. Disable the relevant action at each limit and both actions without an image or while the AI editor is open. Zoom remains available during cropping and does not alter canvas pixels, placement, or Undo history.
- **Verification:** The native keyboard smoke check passed canvas and selected-text Command-C routing, PNG clipboard output, Command-plus/equal/minus, one zoom step per keypress, both zoom limits, unchanged document/history, crop zoom, and crop/AI/empty-state guards. ## Export bounds

- **Entry:** A native Include canvas padding checkbox in the fixed Export controls applies to file export and copying. It is off by default: output contains the visible composition bounds at the layers’ current scales, clipped to the canvas. Turn it on to preserve exact canvas dimensions and intentional padding.
- **Behavior:** Trim transparent margins before adding the selected background or JPG matte. White image pixels and every nonzero alpha value are retained; this does not remove white backgrounds baked into an imported image. Editing geometry, cropping, Undo, preview zoom, and AI input rendering remain unchanged. When every layer is hidden or entirely outside the canvas, image-only export produces a recovery message instead of an empty image.
- **Verification:** 28 tests completed with zero failures and one optional Core ML fixture skipped, including PNG/JPG bounds, retained white image pixels, faint alpha, optional full-canvas output, fractional placement, and clipping. ## Image layers

Select a row or click an image on the canvas; drag and corner-resize affect that layer. Up/down buttons change stack order; duplicate/delete buttons and the row context menu provide stack actions, including Rename. A bounded layer list scrolls to the selected row. Hidden layers remain editable through the list, with a helper explaining that they must be shown to move or resize.
- **Import destinations:** Multi-file opening and image drops support multiple layers. Add Images adds to the current canvas. Paste/open destination choices use a native sheet with Add as Layer / Add as Layers as the prominent default action, followed by Open in New Tab / Open in Separate Tabs and Cancel. Existing layers remain open when imports go to separate tabs; menu and clipboard actions follow the active tab.
- **Editing scope:** Placement, proportional resize, background removal, cutout cleanup, and Restore Original affect the selected layer. Undo restores complete stack state, including layer order, names, visibility, and image changes. Canvas crop shifts every layer together. Export and Copy Image composite visible layers in stack order; Sunburst uses the whole canvas and flattens on Apply, with Undo restoring the stack.

- **Inherited system:** The photographic light table, system colors and font, native control metrics, 276-point inspector, 18-point insets, and fixed Export area remain.
